Datenschutzerklärung PinLine

Zuletzt aktualisiert: 10. Oktober 2026

Kurz gesagt

PinLine arbeitet vollständig auf Ihrem eigenen Computer. Sie brauchen kein Konto, es gibt keine Werbung, und PinLine erhebt keine Statistiken. PinLine sendet nichts über Sie oder Ihren Bildschirm.

Was PinLine auf Ihrem Bildschirm betrachtet

Um Ihre Zeile beim Scrollen wiederzufinden, betrachtet PinLine einen schmalen Streifen des Bildschirms rund um die Linie. Diese Bilder werden im Arbeitsspeicher verarbeitet und sofort wieder verworfen. Sie werden weder gespeichert noch gesendet.

Die Linie selbst erscheint standardmäßig nicht in Screenshots. Nur wenn Sie im Menü ‚Linie im Screenshot zeigen‘ wählen, ist sie eine halbe Minute lang darauf zu sehen.

Maus und Tastatur

PinLine reagiert auf das Mausrad, auf Scrolltasten wie die Pfeiltasten und Bild ab sowie auf Esc. Andere Tasten verwendet PinLine nicht, und was Sie tippen, wird nirgends gespeichert oder gesendet.

Was PinLine auf Ihrem Computer speichert

PinLine legt einige Dateien im Ordner %LOCALAPPDATA%\MarioDigital\PinLine auf Ihrem eigenen Computer ab:

  • Ihre Einstellungen, etwa Farbe, Länge, Sprache und die Gestaltung des Lesezeichens;
  • je Programm, wie weit sich der Text pro Mausrad-Klick bewegt, nur mit dem Namen dieses Programms;
  • eine verkleinerte Kopie des Fotos, das Sie für das Lesezeichen wählen;
  • eine Protokolldatei mit technischen Angaben wie Uhrzeiten, Programmnamen und Bildschirmpositionen. Sie hilft beim Lösen von Problemen.

Diese Dateien verlassen Ihren Computer nicht. Sie können sie jederzeit entfernen, indem Sie diesen Ordner löschen.

Internet

PinLine stellt selbst keine Verbindung zum Internet her. Klicken Sie auf das MarioDigital-Logo oder auf ‚Online-Anleitung‘, öffnet Ihr eigener Browser die Website mariodigital.eu.

Microsoft Store

Wenn Sie PinLine über den Microsoft Store installieren, übernimmt Microsoft die Installation und die Updates. Dafür gilt die Datenschutzerklärung von Microsoft: privacy.microsoft.com.
